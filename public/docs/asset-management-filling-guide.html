3. Asset Form — Depreciation (Finance role only)

FieldOptionsMeaning & example
MethodStraight Line / Life-based (SL) Written Down Value / Rate-based (WDV) Other SL = equal amount each year (uses Life in years). WDV = % of book value each year (uses Rate).
Rate (%)Auto-filled, locked Comes from the category's default rate — cannot be typed. IT Equipment = 20%, Building = 5%.
Expected Life (Years) (SL)Number Useful life for straight-line. Laptop = 5; Furniture = 10.

Note: HOD / Supervisor / End-User can view this tab but only Finance can edit and save it. The rate is always category-driven.

4. Asset Form — SLA (the confusing one, explained)

SLA = the time commitments for responding to and fixing a problem with this asset.

FieldOptionsMeaning & example
SLA SourceBased on Category Custom Based on Category = auto-fills response/resolution from the configured SLA Matrix (recommended). Custom = you type the times manually for this one asset.
SLA CategoryLOW MEDIUM HIGH Criticality of the asset. ICU ventilator = HIGH; waiting-room TV = LOW.
SLA LevelL1 L2 L3 Escalation tier (which support level handles it). In Category mode, only the levels configured for that category appear.
SLA Response Value + UnitNumber + Minutes/Hours/Days/Months/Years Response time = how fast someone must acknowledge / attend. e.g. 2 Hours. (Read-only unless Source = Custom.)
SLA Resolution Value + UnitNumber + unit (same list) Resolution time = how fast it must be fixed. e.g. 24 Hours. (Read-only unless Source = Custom.)
Worked example — ICU Ventilator: Source = Based on Category → Category = HIGH → Level = L1 → Response/Resolution auto-fill (e.g. 30 Minutes response, 4 Hours resolution) from the matrix. You don't type them.
Worked example — Office Printer: Source = Custom → Category = LOW → type Response = 1 Day, Resolution = 3 Days.

7. Store & Inventory Management

FieldOptionsMeaning & example
Store TypeMain Store Sub Store Main = central warehouse; Sub = department store (e.g. IT Sub Store). A Sub Store needs a parent + department.
Stock Item Type (Add/Adjust Stock)Spare Part Consumable Only spares & consumables hold a stock quantity. Assets are tracked individually, not as quantity.
Transfer Item TypeSpare Part Consumable Asset What you're moving. Asset = pick a parked asset from the source store (qty always 1).
Transfer TypeStore to Store Store to Department Store→Store keeps it in inventory at the new store. Store→Department issues it out to a department (pick the To Department).

8. Assignment & Acknowledgement

An asset is handed down a chain: HOD (Source) → Supervisor → HOD (Target) → End User. Each person acknowledges their stage.

FieldOptionsMeaning
HOD DecisionApprove RejectHOD approval of an asset (issues the permanent Asset ID on approve).
Acknowledge — Park into StoreYour department's storeWhen the HOD acknowledges, choose the sub-store the asset is parked into.
Assignment TypePermanent TemporaryWhether the allocation is long-term or short-term.
Activation rule: an asset becomes ACTIVE only when the End User acknowledges the handover, or when its Installed Date is reached. HOD/Supervisor steps keep it IN_STORE.
